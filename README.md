# Classification of Oral Cancer into Precancerous Stages Using LightGBM

## Project Overview
This project focuses on classifying oral cancer into precancerous stages using white-light images and the LightGBM machine learning algorithm.

## Objectives
- Analyze oral white-light images.
- Perform image preprocessing.
- Extract relevant image features.
- Apply LightGBM for classification.
- Support research into early identification of precancerous oral lesions.

## Technologies Used
- LightGBM
- MATLAB
- Machine Learning
- Image Processing
- White-Light Images

## Project Workflow
1. Image Dataset Collection
2. Image Preprocessing
3. Feature Extraction
4. Model Training
5. Classification and Evaluation
